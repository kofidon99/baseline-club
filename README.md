# Baseline Club

Own the baseline, one rally at a time.

Tennis arcade game. Slide to move your racket. Returns are automatic. Aim with the edge of your racket to beat your opponent. First to seven wins.

## Play and host

Double-click index.html to play locally after extracting the ZIP. The game is bundled into that file and does not require a local server. For GitHub Pages, enable Settings → Pages → GitHub Actions. The included workflow publishes the standalone game.

Expected URL after deployment: https://kofidon99.github.io/baseline-club/
